# Heuristics — Tim Ferriss

The full set of operational rules in IF/THEN form, each attributed. These are the corpus's decision rules, distilled for direct application.

## Prioritization and elimination

- IF a task is unimportant, THEN eliminate it before you optimize or delegate it — "doing something unimportant well does not make it important" (*4HWW*, "Elimination").
- IF you feel "busy," THEN treat it as a warning of lazy thinking and ask which 20% of activity is producing the results (*4HWW*; Pareto).
- IF you are planning your day, THEN write a **not-to-do list** alongside the to-do list, and protect it as hard as any task (*4HWW*).
- IF you can only accomplish one thing tomorrow, THEN ask whether *this* task would make you satisfied with the day — and if not, replace it (*4HWW*, on the single-priority test).
- IF a task keeps expanding, THEN impose a short, hard deadline, because "work expands to fill the time available" (Parkinson's Law; *4HWW*).

## Automation, delegation, and income

- IF you plan to automate or outsource a process, THEN first try to eliminate it entirely, and automate only what survives (*4HWW*, "Automation").
- IF an income or product idea is unproven, THEN micro-test demand cheaply — a test page, a small ad spend — before building it or committing capital (*4HWW*, muse-testing).
- IF you outsource a task, THEN document and streamline it first, so you are delegating a clean process rather than exporting chaos (*4HWW*, "Automation").

## Effort and the minimum effective dose

- IF you are about to add more (more training, more restriction, more hours), THEN find the minimum effective dose and stop there — "boiled is boiled" (*The 4-Hour Body*, 2010).
- IF a health or performance protocol is not working, THEN change *one* variable and measure before changing another (n=1 discipline) (*The 4-Hour Body*).
- IF you cannot measure the outcome, THEN instrument it first (weight, body composition, blood work, tracked metric), because decisions without data are dogma (*The 4-Hour Body*).

## Learning

- IF you want to learn a skill fast, THEN deconstruct it into minimal units, select the high-frequency 20%, sequence it, and set real stakes before you drill anything (DiSSS, *The 4-Hour Chef*, 2012).
- IF you are choosing study material, THEN optimize material selection before method, because the wrong material can't be rescued by good technique (*The 4-Hour Chef*).
- IF you are choosing a teacher, THEN pick for teaching ability and transferable technique, not for fame or elite performance (*The 4-Hour Chef*).
- IF you need new material to stick, THEN compress it to one page, schedule frequency to avoid burnout, and encode it against what you already know (CaFE, *The 4-Hour Chef*).

## Fear, decisions, and discomfort

- IF a decision is stalled by fear, THEN run fear-setting: define the worst case in writing, list preventions and repairs, and price the cost of inaction at 6/12 months and 3 years (TED2017; tim.blog, 2017).
- IF a goal feels blocked because the timing is not right, THEN act now and correct course, because "conditions are never perfect" and "someday is a disease" (*4HWW*, "Definition").
- IF you are avoiding a conversation because it is uncomfortable, THEN treat that as a signal to have it — "success can usually be measured by the number of uncomfortable conversations you're willing to have" (*4HWW*).
- IF a problem feels inherently hard, THEN ask "what would this look like if it were easy?" and "what if I did the opposite?" before assuming the difficulty is real ("17 Questions," 2016).

## Attention and inputs

- IF you are consuming information you cannot act on today, THEN cut it (low-information diet / selective ignorance) (*4HWW*, "Elimination").
- IF similar small tasks recur (email, errands, admin), THEN batch them into scheduled blocks instead of handling them continuously (*4HWW*).
- IF you want to model a high performer, THEN extract their concrete routines, tools, and tactics — not their inspirational story — and test one this week (*The Tim Ferriss Show*; *Tools of Titans*, 2016).
